## ⚙️ Core Technical Features

### 1. Dynamic Availability Engine (`AMainFrontPage.jsx`)

* Runs a real-time interval timer (updating every 10 seconds) that randomly toggles availability badges (`AVAILABLE` / `ON-A-CALL`) across team cards to give the front page an active, dynamic support center feel.

### 2. Interactive Card Overlays & Image Loading

* Uses `<RoleCardOverlay roleIndex={...} />` to render customized role badges directly onto avatar cards.
* Features fine-tuned image optimization with explicit dimensions (`600x600`), WebP asset support, and dynamic `fetchPriority` (`eager` for main hero, `lazy` for secondary cards).

### 3. Dedicated Service Detail Pages

* Individual profile pages (`/brett`, `/amber`, `/blair`, `/bruce`) with skill badges, direct status pulses, technical domain breakdowns, and direct support routing links.
